@@ brief
- Tous les frameworks d'agents enveloppent la **même** boucle : envoyer les messages, exécuter les appels de fonctions, recommencer jusqu'à ce que le modèle ait fini. Tu sais maintenant ce qu'ils font sous le capot.
- **OpenAI Agents SDK** (officiel, même API Responses, passage de relais entre agents), **PydanticAI** (le préféré du formateur : fonctions typées, plusieurs fournisseurs), **LangChain / LangGraph** (beaucoup d'intégrations, des graphes pour les flux complexes), **Google ADK** (pour Gemini et Google Cloud). Et d'autres : CrewAI, AutoGen, Semantic Kernel, Smolagents, le tool use d'Anthropic.
- 🔑 **Éviter les agents quand on peut.** Un agent coûte : plus d'appels, plus de latence, plus d'argent (tout l'historique est renvoyé à chaque tour), plus de choses à surveiller, et un comportement moins prévisible.
- Essaie d'abord le plus simple : un RAG avec une recherche et une réponse, une transformation de document, un seul appel au modèle sans outil. Passe à l'agent seulement quand le plus simple ne suffit **vraiment** pas.
