@@ brief
- Écrire `argsort` et le filtre à la main à chaque fois, c'est fastidieux. minsearch a une classe **`VectorSearch`** qui fait le même calcul, avec la même API que l'`Index` du module 1 : `fit` pour indexer, `search` pour chercher, `filter_dict` pour filtrer.
- `vindex = VectorSearch(keyword_fields=["course"])`, puis `vindex.fit(X, documents)` : la matrice des vecteurs, et les documents qui seront renvoyés.
- 🔑 `vindex.search(query_vector, ...)` prend un **vecteur**, pas un texte : on encode la question d'abord. C'est la différence qui obligera, à la leçon 6, à adapter `RAGBase`.
- Sous le capot, c'est exactement le produit scalaire de la leçon 4, après le filtre.

@@ verified
- Avec minsearch 0.2.0, `vindex.search` renvoie les documents **sans leur score** : les clés sont `id`, `course`, `section`, `question` et `answer`. Si tu as besoin du score (pour un seuil, par exemple), garde ta fonction numpy de la leçon 4.
- Un slug mal écrit dans `filter_dict` renvoie `[]` sans erreur, comme pour la recherche texte du module 1.
- Passer un texte au lieu d'un vecteur plante avec `AttributeError: 'str' object has no attribute 'reshape'`.

@@ guide
### 1. L'index

Deux lignes de la leçon. `fit` ne recalcule aucun embedding : il garde `X` et les documents en mémoire.

### 2. Comparer des listes d'id

`[d["id"] for d in vindex.search(...)]` d'un côté, `[d["id"] for _, d in vector_search(...)]` de l'autre. Deux listes Python se comparent avec `==`.

### 3. Si elles diffèrent

Regarde où : souvent, c'est deux documents aux scores presque égaux qui échangent leur place. Affiche les scores de ta fonction pour le vérifier.

@@ hints
- N'oublie pas `filter_dict={"course": "llm-zoomcamp"}` d'un côté et `course="llm-zoomcamp"` de l'autre : sinon tu compares deux recherches différentes.
- Si toutes les listes diffèrent dès le premier résultat, vérifie que `X` et `documents` sont dans le même ordre des deux côtés.

@@ solution
~~~python
from minsearch import VectorSearch

vindex = VectorSearch(keyword_fields=["course"])
vindex.fit(X, documents)

queries = [
    "I just discovered the course. Can I still join it?",
    "Is it possible to enroll late?",
    "How do I run Olama locally?",
    "Where do I submit my homework?",
    "How do I get a certificate?",
]

for q in queries:
    lib = [d["id"] for d in vindex.search(model.encode(q), filter_dict={"course": "llm-zoomcamp"}, num_results=5)]
    mine = [d["id"] for _, d in vector_search(q, course="llm-zoomcamp", num_results=5)]
    print("identiques" if lib == mine else "différentes", "·", q)
~~~

Les cinq lignes doivent afficher « identiques » : c'est le même calcul. Ce que `VectorSearch` ne donne pas : le **score** de chaque document.
