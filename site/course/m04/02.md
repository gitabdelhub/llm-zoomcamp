@@ brief
- La **vérité terrain** (ground truth) : des paires (question, id du bon document). Pour chaque document de la FAQ du cours, un LLM écrit **5 questions** auxquelles il répond ; chaque question est étiquetée avec l'`id` du document.
- 🔑 Chaque document doit avoir un **`id` stable**. Sans identifiant, impossible de savoir si la recherche a ramené le bon document. Et si l'`id` change, toutes les étiquettes deviennent fausses.
- Première **sortie structurée** du cours : au lieu d'un texte à découper, on décrit la forme voulue avec une classe Pydantic (`class Questions(BaseModel): questions: list[str]`), on appelle `responses.parse(..., text_format=Questions)` et on lit `response.output_parsed.questions`, une vraie liste Python.
- Le prompt demande d'utiliser **le moins possible les mots du document** : un vrai utilisateur ne recopie pas la FAQ. Des questions trop proches du texte gonflent les chiffres.
- `evaluation_utils.py` range tout ça dans des fonctions : `llm_structured` (un appel structuré) et `calc_price` (le coût, à 0,75 $ par million de tokens d'entrée et 4,50 $ en sortie).

### 2. Découper en mots

`re.findall(r"[a-z0-9_]+", texte.lower())` donne les mots, en minuscules. Un `set` suffit : on veut savoir si un mot est présent, pas combien de fois.

### 3. Les mots outils

Un petit ensemble écrit à la main suffit : `the a an to of and or in on for is it i my do does how what can be with this that if are you your from at as by when`.

### 4. Les deux prompts

Garde `data_gen_instructions` du cours, et écris une variante qui dit l'inverse : « reuse the exact wording of the record ». Même document, même modèle, même `Questions`.

@@ hints
- Une question qui n'a que des mots outils donnerait une division par zéro : ignore-la.
- `pd.Series(scores).describe()` donne la moyenne, la médiane et les quartiles d'un coup.
- Choisis un document avec une réponse assez longue (plus de 300 caractères) : sur une réponse de deux lignes, les deux prompts se ressemblent forcément.

@@ solution
~~~python
import json
import re

import pandas as pd
from dotenv import load_dotenv
from openai import OpenAI
from pydantic import BaseModel

from evaluation_utils import calc_price, llm_structured

documents = json.load(open("/workspaces/llm-zoomcamp/site/data/faq-llm-2026-05-12.json"))
doc_idx = {d["id"]: d for d in documents}
ground_truth = pd.read_csv("data/ground_truth-new.csv").to_dict(orient="records")

STOP = set("the a an to of and or in on for is it i my do does how what can be with this that "
           "if are you your from at as by when".split())


def words(text):
    return set(re.findall(r"[a-z0-9_]+", text.lower()))


def overlap(question, doc):
    q = words(question) - STOP
    if not q:
        return None
    return len(q & words(doc["question"] + " " + doc["answer"])) / len(q)


scores = [overlap(r["question"], doc_idx[r["document"]]) for r in ground_truth]
print(pd.Series([s for s in scores if s is not None]).describe())


class Questions(BaseModel):
    questions: list[str]


load_dotenv()
openai_client = OpenAI()

data_gen_instructions = """
You emulate a student who's taking our course.
Formulate 5 questions this student might ask based on a FAQ record. The record
should contain the answer to the questions, and the questions should be complete and not too short.
If possible, use as fewer words as possible from the record.
The output should resemble how people ask questions
on the internet. Not too formal, not too short, not too long.
""".strip()
copy_instructions = data_gen_instructions.replace(
    "If possible, use as fewer words as possible from the record.",
    "Reuse the exact wording of the record as much as possible.")

doc = next(d for d in documents if len(d["answer"]) > 300)
for name, instructions in [("cours", data_gen_instructions), ("recopie", copy_instructions)]:
    result, usage = llm_structured(openai_client, instructions, json.dumps(doc), Questions)
    mean = sum(overlap(q, doc) for q in result.questions) / len(result.questions)
    print(f"{name:8} overlap moyen {mean:.2f}   coût {calc_price(usage)['total_cost']:.5f} $")
    for q in result.questions:
        print("   ", q)
~~~

@@ cles
- La sortie structurée | OpenAI structured outputs responses.parse pydantic | Le modèle renvoie un objet Python au format voulu, pas un texte à découper.
