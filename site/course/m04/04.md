@@ brief
- Pour évaluer la recherche, pas besoin du LLM : on lance seulement `text_search` sur chaque question de la vérité terrain, et on regarde si l'`id` attendu revient.
- La **liste de pertinence** d'une question : un 0 ou un 1 par résultat. `[0, 1, 0, 0, 0]` veut dire « le bon document est arrivé deuxième ». `[0, 0, 0, 0, 0]`, qu'il n'est pas dans le top 5.
- 🔑 La fonction prend la recherche **en paramètre** : `compute_relevance(q, search_function)`. Recherche lexicale, vectorielle, hybride : le reste du code ne change pas. C'est le même principe que le RAG, qui se moque de la recherche qu'on lui branche.
- Une liste de pertinence par question, puis toutes ensemble : `compute_relevance_total(ground_truth, text_search)`. La leçon 5 en tirera deux nombres.

@@ constraints

- Une question trouvée avec la FAQ du 12 mai et ratée avec celle d'aujourd'hui, alors que son document existe dans les deux : son rang dans chacune, et ce qui l'a doublée

@@ guide
### 1. Une recherche par index

Écris une petite fabrique : `make_search(index)` renvoie une fonction `search(query)` qui appelle `index.search(query, num_results=5, boost_dict={"question": 3.0, "section": 0.5})`, comme dans la leçon. Tu as ainsi `search_may` et `search_now`, interchangeables.

### 2. Les id absents

Un ensemble des `id` de l'index, puis une compréhension : `missing = {q["document"] for q in ground_truth} - ids_now`.

### 3. Trier les ratés

Une liste ratée est une liste sans 1. Si son `document` est dans `missing`, c'est un document disparu ; sinon, il est hors du top 5.

### 4. La question qui change

Parcours les deux listes de pertinence ensemble avec `zip`. Pour la question choisie, relance la recherche avec `num_results=20` sur chaque index et cherche la position de son document. Puis regarde les documents qui sont passés devant : sont-ils nouveaux depuis mai ?

@@ hints
- Les deux listes de pertinence sont dans le même ordre que `ground_truth` : la question `i` est la même des deux côtés.
- Pour la position : `next((i + 1 for i, d in enumerate(results) if d["id"] == doc_id), None)`.
- Un document nouveau depuis mai, c'est un `id` qui est dans la FAQ d'aujourd'hui et pas dans celle du 12 mai.

@@ solution
~~~python
import json

import pandas as pd
from tqdm.auto import tqdm

from ingest import build_index, load_faq_data

ground_truth = pd.read_csv("data/ground_truth-new.csv").to_dict(orient="records")
docs_may = json.load(open("/workspaces/llm-zoomcamp/site/data/faq-llm-2026-05-12.json"))
docs_now = [d for d in load_faq_data() if d["course"] == "llm-zoomcamp"]


def make_search(index, num_results=5):
    def search(query):
        return index.search(query, num_results=num_results, boost_dict={"question": 3.0, "section": 0.5})
    return search


def compute_relevance(q, search_function):
    doc_id = q["document"]
    return [int(d["id"] == doc_id) for d in search_function(query=q["question"])]


def compute_relevance_total(ground_truth, search_function):
    return [compute_relevance(q, search_function) for q in tqdm(ground_truth)]


index_may, index_now = build_index(docs_may), build_index(docs_now)
search_may, search_now = make_search(index_may), make_search(index_now)
rel_may = compute_relevance_total(ground_truth, search_may)
rel_now = compute_relevance_total(ground_truth, search_now)

ids_may, ids_now = {d["id"] for d in docs_may}, {d["id"] for d in docs_now}
labels = {q["document"] for q in ground_truth}
for name, docs, ids, rel in [("12 mai", docs_may, ids_may, rel_may), ("aujourd'hui", docs_now, ids_now, rel_now)]:
    print(f"{name:12} {len(docs)} documents, {len(labels - ids)} id absents, "
          f"{sum(1 in r for r in rel)} questions trouvées sur {len(rel)}")

missing = labels - ids_now
gone = sum(1 for q, r in zip(ground_truth, rel_now) if 1 not in r and q["document"] in missing)
below = sum(1 for q, r in zip(ground_truth, rel_now) if 1 not in r and q["document"] not in missing)
print(f"ratées aujourd'hui : {gone} document disparu, {below} hors du top 5")


def rank(search, q):
    return next((i + 1 for i, d in enumerate(search(q["question"])) if d["id"] == q["document"]), None)


i = next(i for i, (q, a, b) in enumerate(zip(ground_truth, rel_may, rel_now))
         if 1 in a and 1 not in b and q["document"] in ids_now)
q = ground_truth[i]
wide_may, wide_now = make_search(index_may, 20), make_search(index_now, 20)
print(q["question"])
print("rang le 12 mai :", rank(wide_may, q), " rang aujourd'hui :", rank(wide_now, q))
for d in wide_now(q["question"])[: rank(wide_now, q) or 20]:
    print("   ", "nouveau" if d["id"] not in ids_may else "ancien ", d["question"][:70])
~~~

@@ cles
- La liste de pertinence | relevance judgments information retrieval | Pour chaque résultat, est-ce le bon document ? La base de tous les calculs.
- La dérive des données | ground truth drift dataset versioning | Une vérité terrain n'est valable que pour la version de la base qu'elle étiquette.
- L'intégrité référentielle | referential integrity foreign key | Chaque étiquette doit pointer vers un document qui existe.
