@@ constraints
- `run_batch(records, f, out_path, key="question", max_workers=6)` : lance `f` sur chaque enregistrement, en parallèle
- Chaque résultat est ajouté au fichier `out_path` (une ligne JSON par résultat) **dès qu'il arrive**, pas à la fin
- Relancé, `run_batch` ne refait que les enregistrements dont la clé n'est pas encore dans le fichier

@@ guide
### 1. Le fichier, ligne par ligne

Le format JSONL : un objet JSON par ligne, `json.dumps(result) + "\n"`, en mode ajout (`"a"`). Si le programme s'arrête, toutes les lignes déjà écrites restent valides.

### 2. Plusieurs threads, un seul fichier

Deux threads qui écrivent en même temps peuvent mélanger leurs lignes. Le plus simple : les threads ne font que les appels, et c'est la boucle principale qui écrit, un résultat à la fois. Si tu préfères écrire depuis les threads, protège l'écriture avec un `threading.Lock()`.

### 3. Ce qui est déjà fait

Au début, relis le fichier s'il existe, et garde l'ensemble des clés déjà écrites. Ne soumets que les autres.

### 4. Les échecs

Une petite fonction qui appelle `f(rec)` dans un `try`, et renvoie soit le résultat, soit l'erreur. `as_completed` de `concurrent.futures` donne les tâches dans l'ordre où elles **finissent**, pour écrire chaque résultat tout de suite.

### 5. Le vrai lancement

`run_batch(ground_truth[:20], generate_rag_answer, "data/rag-answers-mine.jsonl")`, avec `assistant.reset_usage()` avant et `assistant.total_cost()` après.

@@ solution
~~~python
import json
from concurrent.futures import ThreadPoolExecutor, as_completed
from pathlib import Path

from tqdm.auto import tqdm


def run_batch(records, f, out_path, key="question", max_workers=6):
    """Lance f sur chaque enregistrement pas encore fait. Chaque résultat est écrit dès qu'il arrive."""
    out = Path(out_path)
    done = set()
    if out.exists():
        with out.open() as fh:
            done = {json.loads(line)[key] for line in fh if line.strip()}
    todo = [r for r in records if r[key] not in done]
    failures = []

    def safe(rec):
        try:
            return rec, f(rec), None
        except Exception as e:  # une erreur n'arrête que cet enregistrement
            return rec, None, repr(e)

    with ThreadPoolExecutor(max_workers=max_workers) as pool, out.open("a") as fh:
        futures = [pool.submit(safe, r) for r in todo]
        for fut in tqdm(as_completed(futures), total=len(futures)):
            rec, result, error = fut.result()
            if error:
                failures.append({key: rec[key], "error": error})
                continue
            fh.write(json.dumps(result, ensure_ascii=False) + "\n")  # seule la boucle principale écrit
            fh.flush()
    print(f"{len(done)} déjà faits, {len(todo) - len(failures)} nouveaux, {len(failures)} échecs")
    return failures


# Le test, sans appel payant
seen = set()


def flaky(rec):
    if rec["question"] in {"q3", "q7", "q11"} and rec["question"] not in seen:
        seen.add(rec["question"])
        raise TimeoutError("réseau")
    return {"question": rec["question"], "answer_llm": "réponse à " + rec["question"]}


fake = [{"question": f"q{i}"} for i in range(20)]
~~~
