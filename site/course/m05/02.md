@@ practice
Ajoute à `assistant.py` un mode **recherche seule** : il affiche les 5 documents que la recherche trouve, sans appeler le LLM. C'est l'outil que tu ouvriras en premier quand une réponse te semblera fausse : le problème vient-il de la recherche ou du modèle ?

@@ constraints
- `uv run python assistant.py --search "How do I join the course?"` affiche 5 lignes numérotées : le cours, la section et la question de chaque document
- Sans `--search`, le script fait exactement ce que fait la leçon
- Le mode recherche n'envoie **aucune** requête au LLM
- Une cible `make search Q="ta question"` dans le `Makefile`

@@ guide
### 1. Lire les arguments

`sys.argv[1:]` est la liste des mots après le nom du script. Regarde si `"--search"` y est, puis retire-le : ce qui reste est la question.

### 2. Chercher sans le LLM

`RAGBase` a déjà une méthode `search(query)` : c'est elle que `rag()` appelle en premier. Chaque document est un dictionnaire avec `course`, `section`, `question` et `answer`.

### 3. La cible make

Dans un `Makefile`, `$(Q)` est remplacé par la valeur passée sur la ligne de commande (`make search Q="..."`). Attention : la ligne de commande sous la cible commence par une **tabulation**, pas par des espaces.

@@ hints
- `enumerate(assistant.search(query), start=1)` te donne le numéro et le document.
- Pour vérifier qu'aucun appel ne part vers le LLM, lance le mode recherche avec `OPENAI_BASE_URL=http://127.0.0.1:9/v1` devant la commande : un appel au LLM échouerait avec `APIConnectionError`.
- Si make répond `missing separator`, ta ligne commence par des espaces.

@@ solution
~~~python
import sys

from dotenv import load_dotenv
from openai import OpenAI

from ingest import load_faq_data, build_index
from rag_helper import RAGBase


def create_assistant():
    load_dotenv()
    documents = load_faq_data()
    index = build_index(documents)
    return RAGBase(index=index, llm_client=OpenAI())


if __name__ == "__main__":
    args = sys.argv[1:]
    search_only = "--search" in args
    args = [a for a in args if a != "--search"]
    query = args[0] if args else "How do I join the course?"

    assistant = create_assistant()
    if search_only:
        for i, doc in enumerate(assistant.search(query), start=1):
            print(f"{i}. [{doc['course']}] {doc['section']} | {doc['question']}")
    else:
        print(assistant.rag(query))
~~~

~~~makefile
run:
	uv run python assistant.py

search:
	uv run python assistant.py --search "$(Q)"
~~~
