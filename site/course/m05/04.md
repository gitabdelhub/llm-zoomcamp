@@ practice
Remplace le `if` de `calculate_cost` par une **table de prix**, et fais en sorte qu'un modèle inconnu ne passe plus jamais inaperçu.

@@ constraints
- Un dictionnaire `PRICES` en haut de `metrics.py` : le nom du modèle, puis le prix d'entrée et de sortie par million de tokens
- Un modèle absent de `PRICES` lève une `ValueError` qui dit quel modèle manque
- Un petit test, sans appeler l'API : un faux `usage` de 1000 tokens d'entrée et 1000 de sortie, le coût attendu, et le cas d'un modèle inconnu
- Les prix viennent de la page des prix d'OpenAI : note la date à côté, en commentaire

@@ guide
### 1. La table

`PRICES = {"gpt-5.4-mini": (0.15, 0.60)}` : un tuple (entrée, sortie). Ajouter un modèle, c'est une ligne de plus, sans toucher au calcul.

### 2. Échouer fort

`PRICES[model]` lève une `KeyError` si le modèle manque. Attrape-la et lève une `ValueError` avec un message utile : une erreur au premier test vaut mieux qu'un tableau de bord qui affiche 0 $ pendant un mois.

### 3. Un faux usage

`from types import SimpleNamespace` : `SimpleNamespace(input_tokens=1000, output_tokens=1000)` se comporte comme `response.usage` pour ta fonction.

@@ hints
- `raise ValueError(...) from None` cache la `KeyError` d'origine dans le message d'erreur : seul ton message reste.
- Pour tester l'erreur sans pytest : un `try` / `except ValueError` et un `print`, ou `pytest.raises` si tu l'installes.
- Avec 0,15 $ et 0,60 $, 1000 + 1000 tokens doivent coûter 0,00075 $.

@@ solution
~~~python
# Dollars par million de tokens (entrée, sortie). Vérifiés sur https://openai.com/api/pricing le : (ta date)
PRICES = {
    "gpt-5.4-mini": (0.15, 0.60),
}


def calculate_cost(model, usage):
    try:
        price_in, price_out = PRICES[model]
    except KeyError:
        raise ValueError(f"Pas de prix pour le modèle {model!r} : ajoute-le dans PRICES") from None
    return (usage.input_tokens * price_in + usage.output_tokens * price_out) / 1_000_000
~~~

~~~python
# test_metrics.py : uv run python test_metrics.py

from metrics import calculate_cost

usage = SimpleNamespace(input_tokens=1000, output_tokens=1000)
assert abs(calculate_cost("gpt-5.4-mini", usage) - 0.00075) < 1e-12

try:
    calculate_cost("gpt-5.4-nano", usage)
    raise AssertionError("un modèle inconnu doit lever une ValueError")
except ValueError as e:
    print("OK :", e)
~~~
