@@ brief
- La recherche **vectorielle** trouve par le sens, la recherche par **mots-clés** trouve les mots exacts (un message d'erreur, un nom de commande). La recherche **hybride** combine les deux.
- Première façon : une **somme pondérée** des scores, `alpha * score_vectoriel + (1 - alpha) * score_mots`. `alpha = 1`, c'est du vectoriel pur ; `alpha = 0`, des mots-clés purs.
- 🔑 Deuxième façon, plus robuste : la **fusion des rangs** (RRF). On ne regarde plus les scores, qui ne sont pas comparables d'une recherche à l'autre, seulement les **places**. Chaque document reçoit `1 / (k + rang + 1)` pour chaque liste où il apparaît, et on additionne.
- Sur l'exemple de la leçon (`k = 1`), C gagne avec 0,750 parce qu'il est bien placé dans les deux listes ; A et B suivent à égalité avec 0,667.
- `k` lisse les écarts : plus `k` est grand, moins la place exacte compte. La fonction `rrf` de la leçon accepte n'importe quel nombre de listes.

~~~python
import json
from collections import Counter

docs = json.load(open("/workspaces/llm-zoomcamp/06-best-practices/documents-with-ids.json"))

same_question = Counter((d["course"], d["question"]) for d in docs)
same_id = Counter(d["id"] for d in docs)
print("questions en double :", sum(1 for n in same_question.values() if n > 1))
print("id en double :", [i for i, n in same_id.items() if n > 1], f"({len(docs)} documents, {len(same_id)} id)")


def rrf(search_results, k=1, num_results=10, key=lambda doc: doc["id"]):
    scores, doc_map = {}, {}
    for results in search_results:
        for rank, doc in enumerate(results):
            kd = key(doc)
            doc_map.setdefault(kd, doc)
            scores[kd] = scores.get(kd, 0) + 1 / (k + rank + 1)
    ranked = sorted(scores.items(), key=lambda x: x[1], reverse=True)
    return [doc_map[kd] for kd, _ in ranked[:num_results]]


example = lambda s: [{"id": c, "question": c} for c in s]
print([d["id"] for d in rrf([example("ABCDE"), example("CBFGA")])])

a, b = [d for d in docs if d["id"] in ("59e86b40", "1ac3ea8f")]
assert a["question"] == b["question"]
print([d["id"] for d in rrf([[a], [b]])])
~~~

@@ cles
- La fusion RRF | reciprocal rank fusion explained | Additionner 1 / (k + rang) sur plusieurs listes de résultats.
- La recherche hybride | hybrid search BM25 vector | Mots-clés et sens dans une même recherche.
- La clé d'identité | entity resolution duplicate keys | Un identifiant qui désigne un seul objet, condition de toute fusion.
