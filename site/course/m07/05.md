@@ practice
Écris une fonction de coût qui ne ment pas : une table de prix, une erreur claire pour un modèle inconnu, et le coût du juge calculé avec le modèle du juge.

@@ constraints
- Un `cost.py` avec un dictionnaire `PRICES` (dollars par million de tokens, entrée et sortie) et une constante `JUDGE_MODEL`
- `calculate_openai_cost("gpt-4o", tokens)` rend un coût plus grand que pour `gpt-5.4-mini`, et un modèle absent de `PRICES` lève une `ValueError` qui dit quoi faire
- Dans `rag`, le coût du juge utilise `JUDGE_MODEL`
- Un `test_cost.py` qui vérifie ces trois points

@@ guide
### 1. La table

Une clé par modèle, `{"input": ..., "output": ...}`. Recopie les prix depuis la page de tarifs d'OpenAI et écris la date en commentaire : ils changent.

### 2. Le calcul

`(prompt_tokens * input + completion_tokens * output) / 1_000_000`. Une recherche exacte (`model in PRICES`) au lieu de `"gpt-5.4-mini" in model`, qui accepterait n'importe quel nom qui contient ce texte.

### 3. Le juge

Dans `rag`, remplace `calculate_openai_cost(model, rel_token_stats)` par `calculate_openai_cost(JUDGE_MODEL, rel_token_stats)`, et passe `JUDGE_MODEL` à `evaluate_relevance`.

@@ hints
- `pytest.approx` compare des nombres à virgule sans souci d'arrondi.
- Pour tester l'erreur : `with pytest.raises(ValueError):`.
- Un nom de modèle daté (`gpt-4o-2024-08-06`) doit lui aussi lever l'erreur, tant que tu ne l'as pas ajouté à la table.

@@ solution
~~~python
# cost.py
# Prix en dollars par million de tokens : à recopier depuis https://openai.com/api/pricing/ (ils changent).
PRICES = {
    "gpt-5.4-mini": {"input": 0.15, "output": 0.60},  # les valeurs de la leçon
    "gpt-4o": {"input": 2.50, "output": 10.00},        # exemple : vérifie-les
}
JUDGE_MODEL = "gpt-5.4-mini"


def calculate_openai_cost(model, tokens):
    if model not in PRICES:
        raise ValueError(f"Pas de prix pour le modèle {model!r} : ajoute-le à PRICES")
    price = PRICES[model]
    return (tokens["prompt_tokens"] * price["input"] + tokens["completion_tokens"] * price["output"]) / 1_000_000
~~~

~~~python
# test_cost.py
import pytest
from cost import JUDGE_MODEL, calculate_openai_cost

T = {"prompt_tokens": 2000, "completion_tokens": 300}


def test_known_models_cost_something():
    assert calculate_openai_cost("gpt-5.4-mini", T) == pytest.approx(0.00048)
    assert calculate_openai_cost("gpt-4o", T) > calculate_openai_cost("gpt-5.4-mini", T)


def test_unknown_model_is_loud():
    with pytest.raises(ValueError):
        calculate_openai_cost("gpt-4o-2024-08-06", T)


def test_judge_cost_uses_judge_model():
    rag_cost = calculate_openai_cost("gpt-4o", T)
    eval_cost = calculate_openai_cost(JUDGE_MODEL, T)
    assert eval_cost > 0 and eval_cost != rag_cost
~~~
